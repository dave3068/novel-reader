novel-reader 桌面端 · V1.1 新功能设计（书架分类 / 阅读历史 / 自定义配色 / 背景图）

依据 .hermes/specs/novel-reader-txt-v1.1/spec.md（R1–R18，基线 v0.3.0）与既有设计稿 novel-reader-desktop-redesign.md 的口径，为 V1.1 四项功能做桌面端界面设计。本稿只做设计、不改代码：样式、令牌、组件形态、文案与状态一律延续现有设计系统（IBM 设计语言 + 主色 #1890ff）。

一、口径与增补二、布局骨架三、分类树 C1–C7四、阅读历史 H1–H3五、自定义配色 T1–T4六、背景图 B1–B4七、状态矩阵 · 追溯 · 落地约束
只承诺规格已定的能力。本稿未引入规格外功能；少数「可选建议」在 §7.4 单列并标注（如阅读页选项面板加一行背景快捷开关），未获裁定前不进入实施。

一、口径与增补

四项功能落在已有三页上：书架（加侧栏与历史视图）、设置（加两个分组）、阅读（加背景层）；不新增顶层导航。所有新尺寸进 UiMetrics、所有新语义由 Rust 投影 —— 这两条是本稿的硬约束（§7.2）。

1.2 组件增补（沿用现有构件形态，不新造视觉语言）

二、布局骨架

三页的纵向预算与既有设计一致（顶栏 48 / 页头 80 / 内容区 558 / 进度条 2 / 状态栏 32 = 720）。V1.1 只在内容区内做加法：书架切「侧栏 240 + 列表」、阅读在正文区叠背景、设置在表单里插两组。

三、分类树（C1–C7，对应 R1–R7 / AC-V11-C）

分类是本期唯一的新导航结构：侧栏树承载层级，浮层承载维护动作（新建 / 重命名 / 移动 / 删除），破坏性动作一律「先选去向、再执行」。所有动作不触碰用户原始 TXT。

四、阅读历史（H1–H3，对应 R8–R9 / AC-V11-H）

「最近阅读」是书架的另一种视图（入口在页头，不在侧栏 —— 门禁 C19）。历史是流水：每次打开记一条，含时间、当时的章节与位置、进入方式；不统计时长。

五、派生式自定义配色（T1–T4，对应 R10–R13 / AC-V11-T）

只让用户调 4 个基色：正文色 / 背景色 / 主色 / 强调色。其余 36 个令牌由 Rust 确定性派生（明/暗两套）；界面负责「看得见派生结果」与「说清风险」，不含任何派生或对比度算法（门禁 C34）。

六、背景图（B1–B4，对应 R14–R17 / AC-V11-B）

背景图全局一张，只作用于阅读页正文区，上面永远叠一层弱化遮罩（默认 85%）。它不参与分页计算：正文的行盒与字节窗口在有/无背景两种状态下逐字节一致。

7.5 可选建议（未获裁定前不进实施）

  • 阅读页选项面板加一行「背景」：显示当前背景开关 + 遮罩强度（与设置页同一投影），便于阅读中快速比较；代价是选项面板多一个分组。
  • 「按书聚合」开关记忆：把开关状态并入 settings（当前设计为界面局部状态，重启回到时间倒序）。
  • 设置页「数据」分组加「导入归类记忆」复位：便于用户反悔「记住我的选择」。
  • 侧栏折叠（< 960）行为细则：收起为 48px 图标栏、点击展开为浮层 —— 断点与形态已给，具体展开宽度与动画待主人裁定。
  • 分类树拖拽排序：sort_index 已在表结构中，界面本期只做「新建在末尾」；拖拽排序留到后续版本（侧栏底部已如实标注）。
