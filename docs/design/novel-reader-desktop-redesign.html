一、设计原则

六条原则对应现状的六个具体缺陷；每条都能在下面的屏里指出落点。

#原则含义现状缺陷 → 落点
P1内容在中心，外壳在边缘正文区只放正文；书名、章节、进度、编码等信息收进工具条与状态栏，且默认弱化（12/14px、secondary 色）。正文区是灰底上的一张白卡，且书名/章节曾压住首行 → S5
P2一屏一个主要动作每屏只有一个实心主按钮；其余为次级/幽灵/图标按钮；图标动作必须带 tooltip。13+ 个同尺寸蓝色块平铺，无主次 → S1、S5、S10
P3动作贴到对象上列表行内不放动作按钮；整行即动作，行级操作以悬浮图标按钮出现；破坏性操作走确认弹窗。每行都挂「跳转 / 选用 / 删除 / 阅读 / 重新关联」按钮 → S1、S6、S7、S8
P4一切状态可见交互控件必须有 default / hover / focus / selected / disabled 五态；聚焦环 2px 主色；错误/警告用状态色 Tag 与 InlineNotification。无 hover/focus 规范，禁用态只是变灰 → S16
P52x 栅格与间距阶所有间距取自 2/4/8/12/16/24/32/48；块间距 ≥ 16；页面外边距 16；尺寸全部来自单一来源常量（不着落于界面层）。间距由字号派生、数值散落 → 二、四
P6键盘与鼠标等价每个鼠标动作都有键盘路径并在快捷键面板中列出；只承诺核心已实现的按键。键盘能力存在但不可发现 → S15

5.4 实现约束（Slint / 门禁，务必先读）

约束落地要求
版式常量唯一来源所有尺寸/字号/颜色常量进 crates/desktop-app/src/layout.rs；app.slint 只保留 UiMetrics 属性声明；新增常量需同步 LayoutMetrics 字段、ui.rs::apply_layout_metrics、tests/layout_constants.rs
界面不得实现阅读语义verify-desktop-scope.py [6] 扫描 .slint：不得出现 encoding/gbk/gb18030/bookmark/pagination 等算法标记；编码/书签/章节语义一律由 Rust 投影为文本与行数据
可用控件集（Slint 1.17.1）内置可用：Button / CheckBox / ComboBox / GroupBox / LineEdit / RadioGroup / ListView · StandardListView / ProgressIndicator / Slider / SpinBox / Spinner / Switch / TabWidget / TableView / ScrollView。**没有** IconButton / Tooltip / Tooltip 容器 / Notification / DataTable —— 这些都是自定义组件（本设计的图标按钮、tooltip、Toast、表格行、进度条均属自绘）
分页与渲染同口径字号、行高、字距、正文区尺寸必须同源；正文渲染逐行、不换行、不加段距/缩进；本轮改动的正文留白（48/32）与可选行宽约束都必须回到同一常量集
可访问性与门禁对等每个新交互入口都要有等价程序化驱动并写入对等性门禁（现状 [8] 界面可达性 的教训）；行/按钮/输入必须带 accessible-label
验证链cargo test -p desktop-app → smoke-desktop.sh --no-build → verify-desktop-input.py → verify-desktop-scope.py → verify-desktop-parity.py → verify-desktop-targets.py（构件换代后刷新 targets.json 证据）
字体与许可界面与正文均无衬线：IBM Plex Sans（OFL-1.1）+ Noto Sans CJK SC（OFL-1.1）；数字用 IBM Plex Mono。若随包分发需登记进第三方许可清单（Slint 同族的「需人工复核」许可族不受影响）
图标本看板图标为自绘几何线框；正式实现建议采用 @carbon/icons（Apache-2.0，可随包）或继续自绘以零依赖。两种都需在许可清单登记

5.5 建议的实施顺序（供后续排期参考，本轮不实施）

阶段内容理由
1令牌层：扩展 layout.rs 常量（顶栏/工具条/状态栏/行高/进度条/圆角/字号）并投影到 UiMetrics后续所有屏都依赖它；也是门禁最容易验证的一步
2组件层：按钮四型 + 图标按钮 + tooltip + Tag + 列表行 + 进度条 + 空态 + 通知（自定义组件，集中在 app.slint 或拆文件）一次性消掉「全是蓝色块」的根因
3阅读页：顶栏 + 工具条 + 状态栏 + 进度条（不动分页口径）核心屏，收益最大；几何事实不变，便于门禁对等
4面板：目录 / 书签 / 选项（含搜索、内联确认、弹窗化）依赖组件层
5书架：表格视图 + 搜索/排序 + 行级菜单需要投影扩展（路径/体积/时间）
6设置表单化 + 数据分组（清理索引、移出书架确认）需要新增 UI 回调
7卡片视图 + 快捷键面板 + 沉浸自动隐藏 + 导入进度增量体验项，可最后做
交付物：本看板（docs/design/novel-reader-desktop-redesign.html）+ 设计规格（docs/design/novel-reader-desktop-redesign.md，含令牌表、组件清单、逐屏规格、功能对照与落地约束）。 两者不含任何应用代码改动；实施需主人另行授权。
