> 配套看板：`docs/design/novel-reader-desktop-redesign.html`（单文件，浏览器直接打开即可预览）
> 状态：**设计交付物，未改动任何应用代码**。实施需另行授权。
> 版本基准：`novel-reader 0.1.0`（Linux x86_64 / x11，Slint 1.17.1，`crates/desktop-app`）

## 0. 本次已定夺的五项口径

| # | 议题 | 结论 |
|---|---|---|
| 1 | 功能边界 | 冻结现有功能 + 少量必要补全进入基线：阅读进度条与跳转、书架搜索/排序/视图切换、书架移出与索引清理入口、快捷键说明面板。V1 范围外能力（连续滚动、全文搜索、ZIP/EPUB 等）仍不出。 |
| 2 | IBM 落地强度 | 采用 Carbon 的栅格、间距阶、组件形态与 IBM UI Shell 结构；主色沿用 `#1890ff`，不引入 Blue 60。 |
| 3 | 字体 | 界面与正文均无衬线：IBM Plex Sans（西文）+ Noto Sans CJK SC（中文）；数字/偏移/版本用 IBM Plex Mono。 |
| 4 | 阅读页信息架构 | 保留「覆盖正文的面板」形态，不引入左右侧栏；面板改为「抽屉式面板 + 面板工具条」，行内不再挂动作按钮。 |
| 5 | 交付形态 | 本规格 + HTML 设计看板；本轮仅桌面端，Android 待后续。 |

设计诊断（现状为何像 demo，逐条可改）：① 无层级——所有动作都是同一个 104×34 蓝色圆角块，一屏 13+ 个同级按钮平铺；② 无栅格与令牌——只有 20/18/14 三档字号，间距由字号派生，颜色硬编码在 `.slint`；③ 无图标与 tooltip，纯文字按钮；④ 面板全部覆盖正文且行内挂「跳转/选用/删除」按钮；⑤ 书架无封面/搜索/排序/空态设计，一行一个大气泡；⑥ 设置页用「减小/增大」按钮对；⑦ 加载/错误态是裸文本。

## 1. 设计原则（每条都对应一个具体缺陷）

| # | 原则 | 含义 | 落点 |
|---|---|---|---|
| P1 | 内容在中心，外壳在边缘 | 正文区只放正文；书名/章节/进度/编码收进工具条与状态栏，默认弱化（12/14px、secondary 色） | S5 |
| P2 | 一屏一个主要动作 | 每屏仅一个实心主按钮；其余为次级/幽灵/图标按钮；图标动作必须带 tooltip | S1/S2/S5/S10 |
| P3 | 动作贴到对象上 | 列表行内不放动作按钮；整行即动作，行级操作以悬浮图标按钮出现；破坏性动作走确认 | S1/S6/S7/S8 |
| P4 | 一切状态可见 | 控件五态齐备（default/hover/focus/selected/disabled）；聚焦环 2px 主色；异常用状态色 Tag 与 InlineNotification | S4/S16 |
| P5 | 2x 栅格与间距阶 | 间距只取 2/4/8/12/16/24/32/48；块间距 ≥16；页面外边距 16；尺寸全部来自单一来源常量 | 二、四 |
| P6 | 键盘与鼠标等价 | 每个鼠标动作都有键盘路径并列入快捷键面板；**只承诺核心已实现的按键** | S15 |

| 阶 | 值 | 用途 |
|---|---|---|
| p10 | `#e6f4ff` | 选中底、通知底、图标按钮选中底 |
| p20 | `#bae0ff` | Tag 底、描边强调 |
| p30 | `#91caff` | 悬浮态描边 |
| p40 | `#69b1ff` | 暗色主题主色 |
| p50 | `#4096ff` | 暗色 hover |
| **p60** | **`#1890ff`** | **主色**：实心按钮、进度条、选中指示 |
| p70 | `#0958d9` | 正文链接、次级按钮文字、hover 实心 |

### 2.3 间距阶（2x 栅格）

`2` 图标与文字 · `4` 图标按钮之间 · `8` 行内元素 · `12` 控件与标签 · `16` 区块内/页面边距 · `24` 区块之间 · `32` 分组之间 · `48` 栏高/正文留白

### 2.5 栅格与断点

基线窗口 **1200×800**（看板按 1080×720 缩比呈现）；16 列 × 16px 沟槽；外边距 16。

| 窗口宽 | 行为 |
|---|---|
| ≥1440 | 表格列宽按比例放大；正文左右留白 64 |
| 1200–1439 | 基线布局 |
| 960–1199 | 书架隐藏「最近阅读」列；正文留白 40 |
| 720–959 | 工具条只留图标；状态栏隐藏版本与编码 |
| 560–719 | 紧凑模式：正文留白 24、工具条 40、书架切卡片视图 |
| <560 | 不保证可用（窗口最小 560×400） |

## 5. 逐屏规格

约定：`→ Rust` 表示界面只上报意图，语义（文案、位置、编码、章节）全部由 Rust 投影；`→ UI` 表示 Rust 只提供数据。

### S1 书架 · 表格视图（默认）

- **结构**：顶栏 48 → 页头 80（标题 24/600 + 计数 Tag；右侧 搜索 240 · 视图切换 · 排序 150 · 主按钮「导入 TXT…」）→ 表头 40 → 行 48 → 状态栏 32。
- **列**：书名/文件（自适应，含路径与体积 mono 11 两行）· 状态 120 · 进度 180（文本 11 + 2px 进度条）· 最近阅读 110 · 操作 80。
- **状态 Tag**：可阅读（绿）/ 需重新关联（红）/ 需重建索引（黄）/ 已移出（灰）—— 文案来自 `source_status.rs` 既有标签常量。
- **交互**：整行单击 = 打开阅读（等价现状「阅读」与 `NR_READER_BOOK`）；行尾「更多」= 重新关联… / 移出书架（S13）/ 重命名；行操作在 hover / 键盘聚焦 / 触屏时可见；Tab 进表、↑↓ 移动、Enter 打开。
- **数据**：`books`（display_name、original_name、source_locator、source_size、status、encoding）+ `reading_progress`（chapter_index、byte_offset、last_opened_at）。**无需新表**；投影需扩展 `ShelfRow`（路径/体积/状态码/最近打开时间）。

### S2 书架 · 卡片视图

- **结构**：与 S1 同页头，内容区 3 列卡片（<960 → 2 列，<720 → 1 列），卡片 320×≈260：封面占位 128（主色 10 底 + 首字 32/600）· 书名 16/600 · 元信息 mono 11 · 进度条 + 章节/百分比 · 主按钮「继续阅读」。异常时卡片头改状态色底 + 图标，动作变「重新关联…」。
- **理由**：面向「找一本继续读」；表格视图面向核对与治理。封面为本地派生占位，不引入网络素材（离线/无遥测边界）。
- **说明**：视图/排序/搜索的持久化建议写入 `reader_settings` 扩展键；不持久化（工作区记忆）亦可接受。

### S3 书架 · 空态

- **结构**：页头 + 居中块（64px 灰图标 + 「书架还是空的」20/600 + 说明 14 最大宽 520 + 主按钮「导入 TXT…」+ 三条补充说明：支持格式 / 编码与手动指定 / 数据位置与备份）。
- **文案纪律**：不得出现内部里程碑代号（现状 `SHELF_EMPTY_HINT` 里的「导入链路在 DT2 接入后可用」必须替换为面向用户的交付文案）；空态/错误态文案由 Rust 投影。

### S4 书架 · 源文件失效

- **结构**：页头 + InlineNotification（error，宽 = 内容区）：标题「N 本书的源文件已失效」+ 一句解释 + 「全部重新关联…」+ 「忽略」+ 关闭；失效行状态 Tag 红、行尾首位图标变「重新关联」；原路径 mono 显示并注明「（当前不可读）」；状态栏显示「书架：12 本 · 1 本待重新关联」。
- **口径**：必须明写「原始 TXT 文件未被修改或删除」；「忽略」只收起通知，本次会话不再出现，但状态是持久事实、下次启动仍提示。

### S5 阅读 · 常态（核心屏）

- **结构**：`48 / 48 / 590 / 2 / 32`。
  - 顶栏：全局导航（不重复阅读页导航）+ 右侧主题 / 快捷键 / 退出。
  - 工具条：左 目录/书签/选项；中「书名 · 章节」居中省略；右 保存进度/沉浸阅读/收起工具条。
  - 正文：左右留白 48、上下 32；逐行渲染，行盒由测量决定（界面不换行、不加缩进/段距/字距）。
  - 进度条：字节千分比可视化，hover 变 4px 并显示「42.3% · 第七章」。

- **交互**：点击正文（手势模式左/右 1/3 翻页、中部收起工具条；按钮模式点中部收起工具条）语义不变；滚轮 = 整页翻页（正文不出滚动条）；键盘 PageUp/↑/← 与 PageDown/↓/→ 保持不变；**进度条点击/拖拽跳转（新增）** —— 换算书内位置后走与目录跳转相同的位置校验入口，并如实回报校验结果。

  - 方案 A（推荐）：正文列最大宽 = 40 × 字号（720px @18px）居中，两侧留白各 132；中文长文舒适行宽 30–40 字/行；仅改桌面侧正文区宽度口径，核心分页语义不变。

### S6 阅读 · 目录面板

- **结构**：面板覆盖正文区（内缩 24 水平 / 16 垂直）：面板头 48（「目录」+ 章节计数 Tag + 搜索 260 + 关闭）→ 行列表 40 → 底部提示条 32（滚轮行为说明 + `7 / 128` 位置读数）；自绘滚动条 8（轨道 g20 / 滑块 g30，hover 主色，可拖拽与点击轨道）。

- **建议项**：Esc / 点击面板外关闭面板（需 `input.rs` 扩展面板级 Esc，未实现前以关闭按钮为准）。

### S7 阅读 · 书签面板

- **结构**：面板头 48（「书签」+ 计数 Tag + **唯一主按钮**「在当前页新增书签」+ 关闭）→ 行列表 40 → 底部重命名区 64（选中项 + 输入框 + 「保存名称」）→ 底部提示条 32。
- **行**：章节读数 mono 12 + 标题 13.5/600 + 位置（偏移量 mono 12）+ 行尾图标按钮（跳转 / 重命名 / 删除，hover 显示）。
- **交互**：单击 = `mark-select`；双击或行尾跳转 = `mark-jump`；新增 = `mark-add`；重命名 = `mark-rename`（输入框聚焦时翻页键屏蔽，沿用 `input.rs` 现状）；删除 = `mark-delete`，**破坏性动作改为行内两段确认**（不弹窗、不误删），完成后状态栏/Toast 给出反馈。

### S8 阅读 · 选项面板（当前承载：编码）

- **形态**：居中弹窗 560 + 遮罩 `rgba(22,22,22,.5)`（仍属「覆盖正文」，符合口径 4）；标题「选项」+ 当前值 mono + 关闭；选项列表行 40（单选 16 + 名称 + 「当前」Tag）；说明文字（对位置保留/重建后果的解释）；底部 [取消] [应用]。
- **理由**：目录/书签是浏览型动作（覆盖式面板 + 滚动列表最合适）；选项是一次性设定，用弹窗才能明确表达「有未决定的选择」并给出取消。
- **语义边界（强制）**：选项行仍由 Rust 投影（`choice-rows`），界面只渲染名称与当前标记。`.slint` 中**不得出现** `encoding` / `gbk` / `gb18030` / `big5` / `detect_encoding` 等 token（`verify-desktop-scope.py [6]` 词法扫描会命中）。
- **交互**：应用 = 现状 `choice-select` 全链路（落库 → 失效内容索引 → 重建目录 → 按字节位置重开 → 保存进度）；取消 = 不改状态（现状缺取消路径）。

### S9 阅读 · 沉浸模式

- **结构**：顶栏 / 工具条 / 状态栏全隐；正文 = 整窗（留白 48）；保留 2px 进度条；顶部 40px 浮出工具条（layer-01 82% + 下边框）在指针进入顶部 24px 区域时出现，移开 1.5s 淡出，键盘聚焦时保持可见。
- **退出三路径不变**：Esc / 点击正文中部 / 浮出工具条右端「退出沉浸」图标按钮，共用同一 `apply_immersive(..., false)`。
- **门禁口径**：沉浸态「正文区 = 整窗」这一几何事实不得因自动隐藏而改变（现状由 `NR-IMMERSIVE` 行断言）。
- **新增开关**：「沉浸时自动隐藏工具条」（默认开），关闭后浮出工具条常驻。

### S10 设置

- **结构**：页头（标题 + 「修改立即生效并保存到本地库（library.db）」）→ 分组「排版」（字体族 Select 240 / 字号 Slider 12–40 + 数值框 / 行距 Slider 1.0–2.4 + 数值框）→ 分组「版式（桌面端暂未生效）」（段距 / 首行缩进 / 左右边距 / 上下边距：整行降级 + 黄色 Tag「暂未生效」+ 顶部一条解释）→ 「外观」（主题 RadioGroup：跟随系统/明亮/暗黑）→「交互」（翻页模式 RadioGroup + 手势分区说明 + 自动隐藏 Switch）→「数据」（书架记录数 / 已移出数 / 数据库位置 mono / 「清理章节索引与分页缓存…」次级按钮）→ 状态栏。
- **表单版式**：标签 + 说明（200px）｜控件；内容区可滚动（滚动条 8）。
- **交互**：改动即时 `→ Rust`（等价现状 `settings-change`）；重排状态显示在状态栏（「正在重排…」→ 完成），不阻塞输入；数值框可直接键入，失焦校验并夹紧，非法输入恢复原值并内联提示。
- **边界**：设置行仍由 Rust 投影（key/label/value/note/effective），界面不解释任何设置语义 —— 仅把渲染换成 Slider / Switch / Radio / Select。

### S11 导入中

- **结构**：居中块 520：图标 32（主色）+ 「正在导入…」20/600 + 文件名与体积 mono + 线性进度条 2 + 百分比 + 四步流程（已完成=绿勾 / 当前=主色箭头加粗 / 未开始=灰）+ [取消导入]（次级）+ 说明「取消不会留下不完整的书架记录」；状态栏「正在导入 · 可继续浏览书架」。
- **交互**：导入期间顶栏导航仍可用；失败转 S12；成功回书架（建议高亮新行）。
- **取消导入属新增能力**：需 Rust 侧支持取消（参考 `reading-ffi` 已有取消语义）；本期不做则移除按钮并如实标注。

### S12 错误态

- **结构**：居中块 560：错误图标 32（红）+ 结论式标题 20/600 + 可理解原因 14 + [重新选择文件…]（主）+ [返回书架]（幽灵）+ 可折叠「技术详情」（mono：错误码 / 路径 / 判定说明）；状态栏「导入失败 · 未创建书架记录」。

### S13 移出书架 · 确认（新增入口）

- **结构**：弹窗 520：标题「移出书架」+ 说明（对象、后果、**原始 TXT 不会被修改或删除**、恢复路径：再次导入同一文件）+ 勾选项「同时删除该书的章节索引与分页缓存」（默认关）+ [取消] [移出书架（Danger）] + 脚注（更强动作「彻底删除记录（含进度与书签）」在行级「更多」中另设确认）。

### S14 清理可重建索引 · 确认（新增入口）

- **结构**：弹窗 560：「将删除（可重建）」栏（chapters / layout_records 计数）｜「将保留」栏（books / book_sources / reading_progress / bookmarks / reader_settings 计数）+ 备份建议（复制 `library.db`）+ [取消] [清理索引（Danger）]。
- **依赖**：`clear_rebuildable_index()` 返回 `IndexClearReport`（含删除量与保留量），直接作为确认与结果信息。完成后 Toast 回报实际删除/保留条数。
- **口径**：清理后索引状态回到「需重建」，不得复用过期章节（现状已有该约束）。

### S15 快捷键说明（新增入口）

- **结构**：弹窗 560，顶栏「?」图标按钮呼出（任何页面）。已实现（正常显示）：上一页 `PageUp`/`↑`/`←`、下一页 `PageDown`/`↓`/`→`、整页翻页 `鼠标滚轮`、退出沉浸 `Esc`。建议项（灰 + 黄 Tag「建议」，实现前不可用）：目录 `T`、书签 `B`、保存进度 `Ctrl+S`、沉浸 `F11`。
- **口径**：tooltip 与快捷键面板必须同源；未实现的快捷键不得写进 tooltip。

## 7. 落地约束（实现前必读）

| 约束 | 要求 |
|---|---|
| 版式常量唯一来源 | 尺寸/字号/颜色常量进 `crates/desktop-app/src/layout.rs`；`app.slint` 只保留 `UiMetrics` 属性声明。新增常量需同步四处：`layout.rs` 常量、`LayoutMetrics` 字段、`app.slint` 的 `UiMetrics` 声明、`ui.rs::apply_layout_metrics`；`scripts/verify-desktop-scope.py` 与 `tests/layout_constants.rs` 双重强制 |
| 界面不得实现阅读语义 | `verify-desktop-scope.py [6]` 扫描 `.slint`：不得出现 `encoding`/`gbk`/`gb18030`/`bookmark`/`pagination` 等算法 token；编码/书签/章节语义一律由 Rust 投影 |
| 分页与渲染同口径 | 字号、行高、字距、正文区尺寸同源；正文逐行渲染、不换行、不加段距/缩进；新设计的留白（48/32）与可选行宽约束都必须回到同一常量集 |
| 界面可达性对等 | 每个新交互入口都要有等价程序化驱动并写入对等性门禁（历史教训：只跑 `NR_*` 驱动时，界面入口缺失不会被发现）；行/按钮/输入必须带 `accessible-label` |
| 验证链 | `cargo test --manifest-path crates/desktop-app/Cargo.toml` → `smoke-desktop.sh --no-build` → `verify-desktop-input.py`（需先 `source /opt/dev-tools/slint-libs/slint-env.sh`）→ `verify-desktop-scope.py` → `verify-desktop-parity.py` → `verify-desktop-targets.py`（构件换代后刷新 `targets.json` 的 `status_evidence`） |
| 字体与许可 | IBM Plex Sans（OFL-1.1）+ Noto Sans CJK SC（OFL-1.1），数字 IBM Plex Mono；随包分发需登记进第三方许可清单 |
| 图标 | 看板图标为自绘几何线框；正式实现可选 `@carbon/icons`（Apache-2.0）或继续自绘（零依赖），两种都需登记许可 |
| 空闲行为 | NFR-D1：静止阅读不得保留无意义动画/定时器/持续出帧 —— 沉浸态「1.5s 淡出」必须由事件驱动而非固定周期出帧 |
| 文案纪律 | 界面不得出现内部里程碑代号；结果/状态文案由 Rust 投影，界面只渲染 |

| O4 | 目录/书签面板的 Esc 关闭与弹窗遮罩点击关闭（需 `input.rs` 扩展） | 建议本期做：改动集中、收益明确（可发现性 + 键盘路径） |
| O5 | 书籍封面占位（S2）是否保留 | 建议保留（本地派生、零依赖）；若主人认为多余，可退为「无封面紧凑卡片」，结构不变 |
| O6 | 卡片/表格视图与排序选择的持久化位置 | 建议写入 `reader_settings` 扩展键；若不愿动设置表，则仅工作区记忆 |

## 10. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 大量新增版式常量未回到单一来源 | 门禁 `verify-desktop-scope.py` / `layout_constants.rs` 直接失败 | 阶段 1 先做令牌层；所有数值只改 `layout.rs` 一处 |
| 自绘组件（tooltip / 表格 / 通知 / 进度条）行为不一致 | 五态与可访问性参差 | 组件层集中在 `app.slint`（或拆独立 `.slint`），统一五态与 `accessible-label`，并配静态判据 |
| 沉浸态自动隐藏工具条引入定时器 | 违反 NFR-D1（空闲不得持续出帧） | 用事件驱动（指针进入/离开 + 一次性淡出定时器），门禁断言空闲期无持续出帧 |
| 新入口无程序化驱动 | 「用户点不到」类缺陷无法被门禁发现 | 每个新入口配等价驱动（如 `NR_SHELF_OPEN=<id>` 的先例）并写入对等性门禁 |
| 正文留白/行宽改动影响分页测量 | 页面留白或裁切异常 | 测量与渲染共用同一常量集；改后跑 `verify-desktop-parity.py` 的 GBK 排版与沉浸视口项 |
| 书架行信息增多导致窄窗口溢出 | 行尾操作按钮被挤出 | 断点规则（960/720）隐藏次要列；行内容 `min-width:0 + elide` |
