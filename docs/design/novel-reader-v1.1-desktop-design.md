## 1. 设计原则（本期新增三条，其余延续既有设计）

| 原则 | 对应缺陷 | 落地 |
|---|---|---|
| **层级靠「位置 + 缩进 + 线」，不靠卡片阴影** | 侧栏、历史组、浮层选择器若都加阴影会糊成一团 | 侧栏与列表之间 1px 线；组内条目靠 2px 竖线 + 缩进；只有浮层用阴影 |
| **危险动作先选去向，再执行** | 「删分类顺手把书也删了」是数据安全事故 | C4 未选去向 → 按钮禁用；H3 清空前说清「不删书籍/进度/书签」 |
| **派生结果可见，算法不可见** | 用户不知道 4 个基色会派生成什么样；算法下沉到界面会破坏跨端一致 | T1 给 8/40 预览色带与对比度读数；`.slint` 不含任何派生/对比度/循环校验 |

## 4. 逐屏规格

> 每屏对应看板中的同名画框（`docs/design/novel-reader-v1.1-desktop-design.html`）。

### C1 书架 · 分类侧栏与过滤

- **结构**：侧栏头 40（「分类」+ 新建）→ 树区（可滚动，行 32）→ 底部说明行 28（可去）。
- **根与未分类**：首行「全部书籍」（常驻、显示全部含未分类）；次行「未分类」= `category_id IS NULL` 的过滤入口，**不是真实分类**（不可重命名 / 移动 / 删除）。
- **选中态**：primary-10 底 + 左侧 2px 主色条 + primary-90 文字 + 图标 primary-70（与列表选中同口径）。
- **过滤**：选中分类 → 列表只显示该分类书籍；页头面包屑同步「分类：全部书籍 / 科幻 / 中国科幻」。
- **计数**：该分类**直接**书籍数（不含子孙）；空分类计数 0 且名称弱化（text-3）。根「全部书籍」= 各分类直接计数之和（画框 C1：24 = 未分类 3 + 科幻 9 + 中国科幻 5 + 外国科幻 4 + 历史 3），侧栏计数、列表内容与页头徽标三者必须自洽。
- **列表与选中一致**：选中「中国科幻」时列表只显示该分类书籍（画框示例 5 本：三体 / 中国科幻简史 / 流浪地球 / 球状闪电 / 超新星纪元），页头徽标显示当前作用域数量（5 本）。
- **状态 tag**：沿用既有 `.tag` 形态；**失败态**（源文件失效）在书架行改用**实心 err 底 + 白字** —— 软底（err-10）在浅色行内辨识度不足，这是本稿对既有 tag 形态的唯一一处强化，其余 tag 不变。
- **规则**：再点已选中的行 → 回到根；「最近阅读」不在此侧栏。

### C2 分类行 · 层级 / 选中 / 行内菜单

- **行状态**：默认 / hover（g10 底 + 行尾浮出「…」24×24，右侧预留 24px 固定槽避免抖动）/ 选中 / 展开（箭头旋转 90°）。
- **行内菜单**（宽 = 侧栏宽，出现在该行下方，阴影 + 1px 边）：新建子分类 / 重命名 / 移动到分类… / 删除…（err 色，永远最后）。
- **非真实分类行**（全部书籍 / 未分类）不显示「…」。
- **键盘**：↑↓ 移动、→← 展开收起、Enter 选中、F2 重命名、Delete 删除；同一时刻只展开一个菜单，Esc / 点击他处关闭。

### C3 新建 / 重命名分类

- **字段**：父分类（只读 + 「更改…」，默认 = 进入时选中分类；root 时 = 「全部书籍」）；名称（单行 40 高，自动聚焦全选）。
- **校验**：trim 后为空 → 按钮禁用 + 提示「请填写分类名称」；同父同名 → 「同一分类下已存在同名分类，请换一个名字。」（不静默改名 / 合并）。
- **重命名差异**：标题「重命名分类」，父分类行换为只读「原名称」，按钮为「保存」。
- **入口**：侧栏头「+」= 根下新建；分类行「…→ 新建子分类」= 该分类下新建；F2 = 重命名。

### C4 删除非空分类 · 去向选择

- **必选**：三个选项默认全空，「删除分类」按钮 disabled；点击不产生任何副作用。
- **计数口径**：文案里的书籍数 = 该分类 + 全部子孙分类下书籍总数。
- **三个去向**：移入另一分类…（展开 `CategoryPicker`）/ 一并移出书架（状态 `removed`，TXT 不动）/ 移回根（未分类）。
- **文案**：标题点名分类；说明同时给出「去向选择」与「TXT 不受影响」；按钮是动作词「删除分类」（err 底白字）。
- **空分类**：不走本浮层，给一次普通确认（标题「删除分类「待读」」）。

### C5 移动到分类（书籍）

- **选择器**：行 36、缩进 18/层、当前目标 primary-10 + 对勾；「未分类」钉在顶部不参与滚动。
- **入口**：书架行「…」与分类行「…」调同一浮层（标题与说明不同）。
- **根不可作目标**：根 = 全部书籍（非分类）；「未分类」才是无归属目标（`category_id = NULL`）。
- **完成反馈**：Toast「已移动到「科幻 / 中国科幻」」；若正过滤来源分类，行随即消失。

### C6 分类移动 · 循环被拒

- **界面层**：自身与全部子孙在目标树中置灰、右侧 tag「不可选」；确认按钮保持 disabled。
- **核心层**：`categories.rs::move` 沿父链上溯拒绝；界面只是投影该判定（门禁 C34：算法不得进 `.slint`）。
- **兜底**：若仍被绕过，Toast「不能把分类移动到它自己的下级分类中。」+ 第二行说明是哪个分类在哪个之下；树结构不变。
- **不做**：不自动改挂到最近合法父级。

### C7 批量导入 · 按目录名归类询问

- **出现条件**：仅「多选文件 / 选目录」时出现；单文件导入直接归入当前分类。
- **预览**：将在当前分类下创建的目录名分类 + 各分类书数；无上级目录名的文件标注「归入「科幻」」。
- **记住开关**：勾选后写入 settings，下次不再询问（复位入口见 §9 可选建议）。
- **两个确认态按钮**：次级「不归类，全部导入「科幻」」；主色「按目录名归类并导入」。
- **完成**：复用既有「导入中」界面，完成后 Toast「已导入 12 本，新建分类 2 个」。

### H1 最近阅读 · 时间倒序

- **行解剖（48）**：时间 110（等宽；今天 HH:MM / 本年 MM-DD HH:MM）/ 书名 + 文件 / 当时的章节与位置 210 / 进入方式 tag 104 / 「…」64。
- **位置语义**：记录的是**打开时刻**的位置，不随后续阅读变化。
- **进入方式 tag**：阅读页打开（b）/ 进度恢复（g）/ 书签跳转（g）/ 章节跳转（g）。
- **行菜单**：打开这本书 / 清除这条（即时，无确认，Toast 反馈）。
- **视图**：不显示分类侧栏；「清空历史」需确认（H3）。
- **空态**：「还没有阅读记录。打开一本书后会在这里留下一条流水。」

### H2 最近阅读 · 按书聚合

- **组头 40**：箭头 + 书名 + 次数 tag + 最近时间 + 「…」（打开该书 / 清除该书的全部流水）。
- **组内 48**：左侧 2px primary-20 竖线 + 缩进 24；书名列显示「—」。
- **排序**：组按最近时间倒序；组内同样倒序。
- **开关状态**：本期只做界面局部状态（重启回到时间倒序）；如需记忆见 §9。

### H3 清空历史 · 确认

- **文案**：「清空全部阅读流水？当前共 20 条记录。只会删除阅读流水：**不会**删除书籍、阅读进度与书签。」
- **辅助**：一行等宽说明「清空后 `books` / `reading_progress` / `bookmarks` 行数保持不变」。
- **按钮**：取消 / 清空历史（err）。取消 = 不发写请求；确认后列表立即变空态 + Toast「已清空 20 条阅读流水」。
- **单条清除无确认**（误删代价小，仍给 Toast）。

### T1 设置 · 自定义配色

- **分组位置**：「外观」之后新增「自定义配色（派生）」。
- **行**：启用开关 → 正文色 / 背景色 / 主色 / 强调色（`ColorSwatchRow`：色块 32 + HEX 等宽 + 选取… + 清除）→ 派生结果（8 色带 + `8 / 40` + 对比度读数 `8.13 : 1` + 通过 tag）。
- **重置为默认**：放在**分组标题行右端**（不占表单行，避免长分组把页面顶出可视区）；不弹二次确认（可逆）。
- **说明块**：「基色不分明暗：切换明/暗时基色不变，只有派生方向随之切换；40 个令牌取值不落库，每次由核心确定性派生。」
- **作用范围**：书架 / 阅读 / 设置三页与全部浮层（弹窗、Toast、遮罩）一次生效（T4 矩阵逐项核对）。

### T2 取色器浮层

- **组成**：2D 色板 200×200 + 色相条 16×200（游标白描边圆点）｜HEX 输入 40 高 + RGB 只读｜对比度读数（仅当编辑正文色或背景色）｜常用 20 色 + 最近使用 8 色。
- **交互**：改动即时预览全窗口；「应用」落库、「取消」回退；Esc 取消 / Enter 应用；不做屏幕拾色（范围外）。
- **校验**：接受 `#RRGGBB`（大小写皆可、可省 #）；非法输入保持原值 + 行内错误。
- **对比度不足**：读数转 warn + 一行提示，**不阻止应用**（T3）。

### T3 对比度不足的提示

- **阅读页**：正文区顶部可关闭提示条（warn 色调）「当前正文/背景对比度 3.82 : 1，低于可读性建议 4.5:1。已保留你的选择。」+ 动作「去设置调整」；状态栏追加 `对比度 3.82:1` warn tag。
- **设置页**：对比度行转 warn + 「低于建议」；组内给建议值与动作「采用建议的正文色 #262626」。
- **口径**：阈值 4.5:1（4.50 通过 / 4.49 告警）；**绝不强改**用户基色；只对「正文对背景」这一对提示。

### T4 自定义配色的作用范围矩阵

- 四张缩略：明·内置 / 暗·内置 / 明·自定义 / 暗·自定义（同一基色反向派生）。
- 需逐项核对五个区域：书架（含侧栏树）/ 阅读（含状态栏与进度条）/ 设置（含聚焦行）/ 浮层（弹窗、遮罩）/ Toast。

### B1 设置 · 阅读背景

- **分组位置**：「自定义配色」之后新增「阅读背景」。
- **行**：背景图（120×68 缩略 + 文件名 + 大小 / 复制时间 / 相对路径）→ 动作行（选择图片… / 移除背景）→ 遮罩强度（滑杆 0–100%，库内千分比）→ 缩放口径（覆盖铺满 / 原始尺寸平铺 / 原始尺寸居中，对应 `fit_mode` 0/1/2）。
- **数据安全**：图片**复制**到 `<data>/novel-reader/backgrounds/`，DB 只存相对文件名（不含 `/`、`..`、非绝对路径）；「移除背景」只删副本与单例行，**不动原图**。
- **说明块**：「不参与分页：背景图与遮罩只影响像素，不影响正文行盒、页边界与字节窗口。」

### B2 阅读页 · 背景呈现

- **三层**：①背景层（`fit_mode` 三选一）②遮罩层（`rgba(背景色令牌, scrim)`，默认 85%）③正文层（测量口径不变）。
- **边界**：背景**不铺**到顶栏、工具条、进度条、状态栏与任何浮层；面板打开时背景仍在正文区（被面板遮住属正常层级）；沉浸模式下随正文区一起长高。
- **口径**：字号/窗口变化照常重排；背景与遮罩不参与测量（AC-V11-B3 逐字节一致）。

### B3 背景加载失败 · 回退

- **回退**：解码失败 / 副本缺失 → 回退**纯色**（当前主题背景令牌），阅读功能不受影响；不黑屏、不占位图。
- **提示**：阅读页顶部 err 提示条「背景图无法读取，已回退到纯色。」+ 动作「重新选择…」「移除背景」；设置页同一状态显示在背景图行。
- **记录保留**：不静默清除 DB 记录；只有用户显式「移除背景」才清记录与副本；启动只尝试一次解码，不做后台重试轮询。

### B4 配色 × 背景 独立性矩阵

- 四张缩略证明：换配色不丢背景、换背景不丢配色；两表（`reader_theme_custom` / `reader_background`）互不引用；「重置配色」不影响背景，「移除背景」不影响配色。

## 5. 状态矩阵与文案清单

### 5.1 状态（空 / 正常 / 异常 / 恢复）

| 区域 | 空态 | 异常 | 恢复路径 |
|---|---|---|---|
| 分类树 | 「全部书籍 + 未分类」两行 + 一行提示「还没有分类。用『+』新建，或在导入时按目录名归类。」 | 同父同名（浮层内错误）/ 循环移动（置灰 + Toast，树不变） | 改名字 / 换目标；无需重启 |
| 分类下书籍列表 | 「该分类下还没有书。可把书移动到此处，或在导入时按目录名归类。」 | 源文件失效 → 沿用既有通知条 | 「全部重新关联…」既有入口 |
| 阅读历史 | 「还没有阅读记录。打开一本书后会在这里留下一条流水。」 | 目标书籍被硬删除 → 流水随书籍级联消失（核心行为，不额外提示） | 无（可再生成） |
| 自定义配色 | 未启用 → 基色行显示内置值 + 置灰「清除」 | 对比度 < 4.5:1 → 阅读页提示 + 设置页 warn | 「采用建议值」/ 手动改色 / 重置为默认 |
| 背景图 | 未设置 → 缩略占位 + 「移除背景」禁用 | 副本缺失/损坏 → err 提示条 + 设置页 err 行，回退纯色 | 「重新选择…」/「移除背景」 |
| 批量导入归类 | —（不在流程中） | 部分文件读取失败 → 沿用既有导入结果清单 | 重新导入失败清单 |

### 5.2 固定文案（实现时照抄，不得改写为内部术语）

- 同父同名：「同一分类下已存在同名分类，请换一个名字。」
- 循环移动：「不能把分类移动到它自己的下级分类中。」
- 未选去向：「请先选择书籍去向 —— 未选择时不会执行删除。」
- 移出书架完成：「已将 7 本书移出书架（原始文件未改动）。」
- 清空历史确认：「清空全部阅读流水？只会删除阅读流水：不会删除书籍、阅读进度与书签。」
- 对比度不足：「当前正文/背景对比度 3.82 : 1，低于可读性建议 4.5:1。已保留你的选择。」
- 背景读取失败：「背景图无法读取，已回退到纯色。阅读功能不受影响。」
- 导入完成：「已导入 12 本，新建分类 2 个。」

## 7. 落地约束（实现前必读）

1. **尺寸零写死**：§2.1 常量全部进 `UiMetrics`（`layout.rs`）；`.slint` 连注释都不许出现带单位的写死值。
2. **语义零下沉**：派生 / 对比度 / 循环校验 / 相对路径校验 / 历史排序聚合全部在 Rust；`.slint` 只接受投影（变异测试 C34 会抓）。
3. **侧栏无「最近阅读」**：门禁 C19 扫 `.slint` 断言；入口固定在书架页头。
4. **背景图运行时解码**：读取路径必须带 `scope-allow:` 注释（说明读的是用户图片文件，不是书籍正文），否则撞 `UNBOUNDED_READ_TOKENS`。
5. **分页口径不动**：背景层与遮罩层是纯绘制层；正文测量、页边界、字节窗口路径不得出现背景相关分支（C42/C43 变异测试）。
6. **每个新入口配 `NR_*` 驱动**并登记进 `verify-desktop-scope.py` 的「界面可达性」对等清单（C50）。
7. **文案不得出现里程碑代号**；空态/错误态只描述现象与下一步。
8. **测试与证据**：实现后按 `tasks.md` 的门禁顺序（`cargo test` → `smoke-desktop --no-build` → `verify-desktop-input`（先 source slint-env.sh）→ `verify-desktop-scope` → `verify-desktop-parity` → `verify-desktop-targets`）留证据。
